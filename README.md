# Iris Binary Logistic Regression

Binary logistic regression implemented from scratch using NumPy to classify two Iris flower species (Setosa vs Virginica) based on sepal features.

## What This Project Does

- Implements logistic regression manually — no sklearn for training
- Binary classification: Setosa (y=0) vs Virginica (y=1)
- Features used: sepal length and sepal width
- Trained with gradient descent over 3000 epochs
- Tracks cost and accuracy history per epoch

## Tech Stack
- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn (dataset + train/test split only)
- Google Colab

## Key Concepts Covered
- Sigmoid activation function
- Binary cross-entropy loss
- Gradient descent parameter updates
- Feature bias term (intercept)
- Stratified train/test split (80/20)
- Decision boundary visualization

## How to Run

Open `Iris_Binary_Logistic_Regression.ipynb` in Google Colab and run all cells.
